# KinVoice — clickable prototype

Front-end only prototype of **KinVoice**, from *PRD KinVoice v2 — Verifikasi Pola Bicara Keluarga Melawan Penipuan Suara AI*.
React + TypeScript + Vite. No backend: every phone runs off one shared, simulated family “world” with mock data.

```bash
npm install
npm run dev          # http://localhost:5173
npm run copy-guard   # PRD copy rules + feature traceability
npm run build
```

See `docs/PRODUCT.md` for the product spec and `docs/ROAST.md` for the design critique and what changed because of it.
